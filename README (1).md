# Java Programming Assignment

This repository contains two Java programs:

1. `PrimeNumbers.java` — displays all prime numbers from 0 to 500.
2. `Fibonacci.java` — displays the first 100 numbers in the Fibonacci sequence.

## How to run

Open a terminal in this folder and run:

```bash
javac PrimeNumbers.java
java PrimeNumbers
```

To run the Fibonacci program:

```bash
javac Fibonacci.java
java Fibonacci
```

Both programs use standard Java. The Fibonacci program uses `BigInteger` so that all 100 values are calculated without integer overflow.
